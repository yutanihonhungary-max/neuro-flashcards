# 脳解剖学 単語帳(Signorelli 口頭試験)

Bari大学 BEMC の Neuroanatomy(Signorelli教授)口頭試験用の一問一答アプリ。467枚。

- `index.html` — 章別版(講義スライドの9章+概説)
- `day/index.html` — Day別版(21日間の学習ルートの順。各Dayに復習ボタンあり)

使い方:カードをタップで答え表示。「分かった」でそのカードを外し、「分からなかった」でデッキの一番後ろへ。全部分かったら最初から。過去問で聞かれた項目には★、有名なゴロ合わせは備考に表示。

ブラウザで開くだけで動く単一HTMLファイル。進み具合は保存されない。
