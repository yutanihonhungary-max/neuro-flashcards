# 脳解剖学 単語帳(Signorelli 口頭試験)

Bari大学 BEMC の Neuroanatomy(Signorelli教授)口頭試験用の一問一答アプリ。467枚。

- `index.html` — 章別版(講義スライドの9章+概説)
- `day/index.html` — Day別版(21日間の学習ルートの順。Anki と同じ間隔反復。各Dayの復習は前の全Dayから期限のカード)

使い方(章別版):カードをタップで答え表示。「分かった」でそのカードを外し、「分からなかった」でデッキの一番後ろへ。全部分かったら最初から。Day別版は「もう一度・難しい・正解・簡単」の4つで答え、次に出す日が Anki と同じ計算で決まる。過去問で聞かれた項目には★、有名なゴロ合わせは備考に表示。

ブラウザで開くだけで動く単一HTMLファイル。進み具合は端末のブラウザに保存され、同じ同期コードの端末どうしで自動で合わさる(ホームの「☁ 端末間の同期」、`sync.js`)。
